Install from the update site

Update site URL (for DBeaver)

https://monosabio.github.io/html-export-update-site/
  1. In DBeaver Community 26.2.5, choose Help > Install New Software... and click Add...
  2. Enter Name HTML Export and Location https://monosabio.github.io/html-export-update-site/, then click Add.
  3. Check HTML Export for DBeaver Community, click Next > twice, accept the Apache License 2.0 and click Finish.
  4. DBeaver asks two security questions. Trust Authorities: trust only https://monosabio.github.io. Trust Artifacts: trust the PGP row only if its fingerprint is the signing key below.
  5. Click Restart Now. Then open Window > Preferences > Editors > Data Editor > HTML Export, set the paths of Python and of the DBeaver Export generator, and click Verify configuration.

To update later: Help > Installation Information, tab Installed Software, select HTML Export and click Update... (Check for Updates only updates DBeaver itself).

If DBeaver has no network access: download the ZIP, then choose Help > Install New Software... > Add... > Archive... and select it. To receive updates, add the update site URL later.

Requirements

  • DBeaver Community 26.2.5 on Windows 11 x64 or Linux x86_64 (the Java 21 bundled with DBeaver is enough).
  • Python 3.10 or newer.
  • DBeaver Export generator 26.19.1, unmodified, installed separately. This site does not distribute it; without it, HTML Export installs but cannot generate reports.

Complete installation guide

Instalar desde el sitio de actualizaciones

URL del sitio de actualizaciones (para DBeaver)

https://monosabio.github.io/html-export-update-site/
  1. En DBeaver Community 26.2.5, elegí Help > Install New Software... y pulsá Add...
  2. Escribí Name HTML Export y Location https://monosabio.github.io/html-export-update-site/, y pulsá Add.
  3. Marcá HTML Export for DBeaver Community, pulsá Next > dos veces, aceptá la Apache License 2.0 y pulsá Finish.

Para actualizar más adelante: Help > Installation Information, pestaña Installed Software, seleccioná HTML Export y pulsá Update... (Check for Updates solo actualiza el propio DBeaver).

Si DBeaver no tiene acceso a la red: descargá el ZIP, elegí Help > Install New Software... > Add... > Archive... y seleccionalo. Para recibir actualizaciones, agregá después la URL del sitio.
